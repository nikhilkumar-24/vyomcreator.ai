HOW TO USE:
================================================================================

For End Users:
  1. Visit vyom.ai website
  2. Upload a video (MP4, MOV, or WebM, max 25MB)
  3. Fill in content details
  4. Click "✦ Analyze my reel"
  5. Watch the animated loader while analysis runs
  6. Select language from dropdown (English, हिंदी, ಕನ್ನಡ, தமிழ்)
  7. Read your personalized content report

For Developers:
  • See CODE_EXAMPLES.md for implementation details
  • See LANGUAGE_SUPPORT.md for user documentation
  • Frontend: index.html + styles.css
  • Backend: functions/api/analyze.js
